
<Callout>
  The postinstall script fetches the binary for the installed version from the GitHub release
  <code>v&lt;version&gt;</code>. pnpm 10 skips dependency install scripts by default; add
  the package to <code>onlyBuiltDependencies</code> so the download runs.
</Callout>

## Requirements

| Requirement | Value |
| --- | --- |
| Node.js | `>=18` (`engines` in package.json) |
| Astro | `^5.0.0`, `^6.0.0` or `^7.0.0` (peer dependency) |
| Platforms | macOS arm64, Linux x64 and arm64, Windows x64 and arm64 |

<Callout type="caution">
  Intel macOS (<code>darwin-x64</code>) is no longer shipped since 0.7.0. The postinstall step
  fails there with <code>Unsupported platform: darwin-x64</code>.
</Callout>
